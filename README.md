# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/53083c42-2a6e-4085-ba2b-ce9c52490c94

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`

## Media uploads

Project photos, videos, and cover images are uploaded directly to Cloudinary
using a signature generated by `/api/cloudinary-signature`. The portfolio JSON,
project PDFs, and CV are stored in Vercel Blob through `/api/projects` and
`/api/upload`.

In Vercel, link a Blob store or set `BLOB_READ_WRITE_TOKEN`. For Cloudinary,
set either `CLOUDINARY_URL` or all three of `CLOUDINARY_CLOUD_NAME`,
`CLOUDINARY_API_KEY`, and `CLOUDINARY_API_SECRET` as server-side environment
variables, then redeploy. For local development, put these values in
`.env.local`. Never expose these credentials through `VITE_` variables or in
client-side code.
